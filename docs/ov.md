## 4. 说明

- 成员元数据通过 `dev_idx` 解析，而不是通过后端句柄传递。
- 读路径可能在多个副本之间重试；写路径可能同时提交到多个设备。
- 恢复流程会先合并超级块、日志和分配器状态，然后文件系统才会进入就绪状态。
- 这些图刻意保持高层级，用于支撑后续的对齐审查。
